Joint source diagnostics — 25 October 2026

Final conclusions

All four arms completed successfully, with the batch finishing around 13:37 Amsterdam, before its 13:49:57 cap. No GPU training remains active in this batch. Earlier sections below preserve the original protocol and intermediate observations.

  1. The network can represent a map layout. The original-objective one-map test reached mean fresh-noise height correlation 0.9980 and mean strongest-start peak error 0.5 world units across two seeds. This is memorization only, not learning a useful distribution of unseen maps. Absolute values remained wrong.
  2. Reducing LR avoided the earlier instability within this test. The full restart from pilot update 2,074 used the same objective, batch, dataset, augmentation, optimizer state and sample/noise sequences, with LR reduced from 0.0002 to 0.00005. It ran through update 4,971 without the original collapse near update 4,412. Held-out t500 loss decreased smoothly from 0.02745 to 0.02335. That is only 2.3% above the old long run's 0.02283 after about 6.7 additional hours. This strongly supports testing optimization before extra capacity or long compute budgets, but one restart does not establish indefinite stability. Fresh full-cohort generation remains blurry and overpopulated.
  3. Foreground weighting addresses one error and exposes another. At the same lower LR and twelve-minute budget, balancing reduced mean fresh foreground MSE from 0.01849 to 0.00877 (52.6%). Strongest start peaks became exactly aligned in both seeds. However Start A density integral worsened from 170.1 to 191.8 against a target of one. RGB/terrain fitting also slowed relative to the original-LR one-map run. Local reconstruction and global quantity semantics require separate metrics; foreground reweighting is not a complete fix.
  4. Sampler settings alone did not recover useful maps. Additional DDIM steps and weaker CFG did not fix global blur. Consistent epsilon recomputation after clipping reduced density accumulation, but did not calibrate quantities.

The evidence does not justify more parameters or weeks of unchanged training. The next source-only joint experiment should test an objective/representation that explicitly learns layer totals and suppresses background mass, while retaining stable optimization. A global source-quantity loss can be computed from existing heatmaps without adding analytical spatial inputs or inference repair. Progressive 4–16-map fitting and fresh-noise evaluation should precede another full-cohort long run. No such follow-up is claimed trained here.

Three focused tests passed: the velocity/DDIM equations reconstruct a known source with an oracle predictor; the diagnostic legacy sampler reproduces the frozen original implementation; and foreground balancing handles both rare activity and genuinely empty layers without division errors.

The normal source Start A integral is one. These are density sums, not decoded start counts. Removing bounds produces invalid negative densities; a sum near one due to negative cancellation is not success. Correcting the epsilon estimate after clean-estimate clipping reduces accumulation, but does not solve amounts or visibly fix global structure. More DDIM steps or weaker CFG alone did not fix the blur. Raw network weights were not clearly better than EMA.

Held-out denoising was also evaluated at t=100, 500, 900 and 990. At t=500, the frozen EMA reproduced its recorded 0.0228252 loss exactly. Clean reconstruction degrades as the source becomes mostly noise: height MSE was 0.00518 at t=500 and 0.06156 at t=990; red-channel MSE was 0.01470 and 0.07752. This motivates testing generation rather than relying on a single intermediate noise level.

The source-weight audit uses 64 deterministically sampled training maps. About 0.46% of the actual float16 loader's Start A pixel weight covers nonzero target activity (about 0.49% before cache quantization). Sparse roles can therefore have low aggregate denoising errors while localization/count calibration remain bad. An empty-layer baseline and training-derived scalar means are recorded in objective_audit.json; these are evaluation baselines, not neural inputs.

All arms retain the 73,323,149-parameter network, thirteen original source targets, twelve rating inputs, the original physical/encoded dataset and zero source spatial conditions. No SDF, pathing, terrain mask or repair is introduced.

The fixed map contains water, natural reclaim, wrecks, civilians and both marker types, so all outputs are exercised. Single-map arms start fresh with identical seeds and effective batch six. Augmentation, feature dropout and rating dropout are disabled. Their evaluations reuse the training map and establish only memorization, not generalization. Fresh seeds 303 and 404 are generated every five minutes, with no source spatial inputs. Source/target strips, terrain/RGB correlations, start-peak distance, foreground MSE and physical density sums are saved alongside multi-noise denoising losses.

The balanced objective leaves height, water and RGB losses unchanged. For nonempty entity/value layers, half the channel objective is ordinary pixel MSE and half is weighted by normalized continuous source activity. Empty layers use ordinary MSE. This changes training weights only; it adds no input/target layer and no analytical or eligibility mask. The baseline/lower-LR pair isolates LR; the lower-LR/balanced pair isolates the sparse-layer objective. Different objective values are not compared as if they were the same loss: common evaluation metrics and raw generation are used instead.

The full-cohort arm restarts from the preserved pilot update 2,074, not the late recovered checkpoint. It inherits model, EMA, optimizer and random states, keeps augmentation/dropout, effective batch 24 and the original objective, and changes only the learning rate. This should cross the original deterioration point around update 4,412 with matching sample/noise sequences. The schedule remains constant during this controlled LR test; LR decay is not claimed tested. Pre-clipping gradient norms and output-weight norms are recorded every 100 updates.

First fresh-generation result

At approximately five minutes in the first one-map arm (update 997), fresh-noise height had 0.978 correlation with the fixed training target. The strongest Start A/B peaks were 0 / 2 world units from their source positions. The generated shoreline also follows the source layout visibly. This is evidence that the network/sampler can learn a complete spatial template; it does not prove learning the full multi-map distribution or create a novel map.

Sparse density sums remain badly biased, and RGB correlation was only roughly 0.19–0.34 across channels. Later arms are required to assess whether balancing or a lower LR helps. These early figures must not be treated as final arm results.

The original-objective one-map arm subsequently completed 2,365 updates in 12 minutes. Seed-303 fresh-noise height correlation reached 0.9980, start peak distances remained 0 / 2 world units, and RGB channel correlations were roughly 0.55–0.63. The shoreline and terrain template are visibly reproduced. Density sums remain biased: Start A integral was 139.6 instead of one. This separates ability to represent a map layout from density/background errors and learning the multi-map distribution. Other controlled arms remain pending.

An oracle test reconstructs the actual 13-channel source exactly in float32. Artificial bfloat16 velocity rounding alone changes start integrals by about 0.2%; artificial input/output rounding produces roughly 15–41% errors depending on clipping. This simplified oracle is not a learned-network precision test, but does not reproduce the observed hundredfold excess density. Sampler algebra or rounding alone is not an adequate explanation of the learned failure.
