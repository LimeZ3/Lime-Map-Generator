Full-Map Symmetry Comparison

Return to the existing full-map joint height/water/depth checkpoint. The half-map training experiment remains preserved but is not used here. No new training, source extraction, resource/prop generation or game export is performed.

Matched Cases

Four seeds (101, 202, 303, 404), three requested water fractions (0%, 20%, 40%), and five patterns: 180-degree rotation, X reflection, Z reflection, diagonal and antidiagonal reflection. This gives 60 cases. Each case has eight terrain views:

Method Operation
Raw Unmodified output from the full-map model
Average Average the physical fields with their transformed copies
Copy A Keep one side and transform it onto the other
Copy B The opposite side wins instead
Water-aware Rank complete symmetry orbits to retain the original water amount; reconcile height sign and depth
Refine 250 Water-aware candidate, noised to t=250, then 50 constrained denoising steps
Refine 500 Same candidate/noise seed, but t=500 and 50 denoising steps
Projected noise Generate a full map from symmetric unit-variance noise, enforcing symmetry throughout 100 denoising steps

All enforcement methods within a case share exactly the same original full map, spawn anchors, requested profile and checkpoint. Projected-from-noise is an additional sampling control, not postprocessing of the original map.

Anchor pairs are chosen so each pattern swaps player A and B. Rotational and antidiagonal cases share the same original; other patterns use different anchor layouts. Comparing patterns is consequently not an identical-input experiment. 90-degree/fourfold symmetry is deliberately excluded from this two-player pilot.

Important Details

  • All three structural channels receive the same spatial transformation.
  • Diffusion noise has unit marginal variance on both paired cells and fixed-axis cells; simply averaging independent noise would reduce its variance.
  • Water-aware correction preserves the original raw water-cell count to within one cell, not the requested profile percentage. Its fixed score is half averaged SDF plus half negative height scaled by four. This is a heuristic constrained correction, not a learned optimizer. Changed coastlines can still be poor.
  • Water distance is recomputed using the existing SciPy distance transform.
  • Refinement may change the water amount again. It is not silently calibrated afterward, so that effect remains visible.
  • No central seam smoothing is applied. Copying is shown honestly, including bad rotational joins.
  • Every method is also passed through the same existing height/water decoder. Field previews and common-decoder previews stay separate.
  • Native 513x513 resampling error is measured before exact symmetric projection; raw originals are not projected. Generated arrays are preserved with hashes.
  • Image height ranges are shared across all eight methods within each case.
  • Land routes/buildability are approximate structural tests, not game verification.

Windows Commands

The existing CUDA environment does not include SciPy. Use it for inference, and the existing CPU/scientific environment for deterministic processing and reporting. No dependency installation or environment changes are needed.

$env:PYTHONPATH = 'src'
.venv/Scripts/python.exe -m supmapai.tools.compare_terrain_symmetry generate `
  --checkpoint data/models/terrain_joint_10km_1v1_long_v1/best.pt `

.venv-codex/Scripts/python.exe -m supmapai.tools.compare_terrain_symmetry postprocess `

  --run data/models/terrain_symmetry_comparison_v1

Use a new output directory for a new experiment. Refinement can be rerun after an interruption: already recorded variants are hash-checked and skipped. Per-phase code snapshots, checkpoint identity and environment versions are recorded.

Review

Open data/models/terrain_symmetry_comparison_v1/index.html locally. It contains pattern, seed, water and field/decoder view selectors, with all eight methods alongside each other. No server or deployment is needed. Individual PNGs, wide contact sheets, arrays, metrics.csv, metrics.json and report.md accompany it.

Look for terrain continuity, sensible water basins and shorelines, retained relief, and coherent base-to-base geography. Metrics include water IoU/area changes, height changes, boundary gradients, water components and approximate land routes. No combined mathematical score is claimed to replace player judgment.

Completed Pilot

All 60 cases and 480 comparison views completed. This includes 60 asymmetric raw references and 420 symmetric variants. Every symmetric field and common-decoder native vertex grid passed exact symmetry checks; the raw references remain unchanged. Water-aware correction met its one-cell area tolerance in all cases.

Generation took 72.2 seconds for 48 unique originals (rotational and antidiagonal cases reuse the same inputs). Diffusion refinement and constrained generation took 177.5 seconds. Deterministic processing and reporting are recorded separately in their phase JSON files. No training was performed.

For the 12 rotational cases, pooled across four seeds and three water controls:

Height values are world units. Water changes are percentage points relative to each raw original, not errors against the requested control. Area preservation does not imply shoreline preservation. The common decoder and approximate land routes are not a substitute for in-game verification.

Initial interpretation: direct rotational copying repeats the problematic join. Water-aware correction avoids whole-map water loss, while light refinement is a promising next candidate for coherent symmetric terrain. Stronger refinement changes more of the original without a clear benefit in these diagnostics. Constrained-from-noise is not clearly superior. No permanent default was changed.

Axis-aligned reflection has zero difference across its central cell pair by construction, including for copying. That value does not establish the absence of artificial ridges or valleys. Height-change MAE and water IoU also must not be used as standalone quality rankings: symmetric projection inevitably modifies an asymmetric source.

Twenty-nine focused terrain tests passed. Browser QA covered all 120 combinations of pattern/seed/water/view with eight successfully loaded images each, no JavaScript errors, and no horizontal overflow at a 390-pixel mobile viewport. Desktop/mobile screenshots and the check result are saved under the experiment's qa/ folder.

Native Game Export Pilot

On 23 October 2026, four newer full-map symmetry samples were exported and installed in the active FAF maps directory:

In-game name Source case Method
MapGen Symmetry Rot101 Average rotate180_seed101_water20 average
MapGen Symmetry Rot101 Refine250 rotate180_seed101_water20 refine250

MapGen Symmetry Rot303 Water rotate180_seed303_water40 water_aware

Outputs and file hashes are recorded in data/exports/symmetry_native_v1/manifest.json. These exports use the saved 513x513 common-decoder heights, not a template's terrain. Source arrays are hash-checked. Native uint16 heights, water elevation, preview, normal maps, water masks and terrain types are rebuilt. Old template props, decals and waves are removed; base materials and lighting are inherited from Adaptive Canis River. No texture model is involved. Sea level is translated to 128 world units without rescaling relative relief.

Each 10x10 km map has two symmetric spawn markers, 16 mexes and two hydros. These are deterministic test placements, not model output. Small dry, flat footprints are repaired locally; there is no reclaim. Exact height/marker symmetry, dry flat footprints and binary height read-back passed on all four maps. Approximate land connectivity passed too, but does not certify engine pathing or competitive balance. Four new export tests and 29 existing terrain tests passed.
