Resource icons and two-slot FFA fix — 2026-10-14

Mass/energy images are the original 20×20 Supreme Commander Forged Alliance build UI icons, converted unchanged from textures.scd: textures/ui/common/game/build-ui/icon-mass_bmp.dds and icon-energy_bmp.dds. Mass values use green; energy values use yellow. The same icons appear in reclaim overlay controls. Other field/question icons use the existing Lucide icon system, with text labels retained.

FFA is unavailable in assessed configurations, other suitable configurations and gameplay modes when capacity is two slots or fewer. Unknown capacity still permits FFA. The Player slots correction override retains team-size choices, while known two-slot maps still exclude FFA. Server validation rejects FFA in all three fields. Historical data is retained; opening an old incompatible review initializes valid choices for a new correction.

Verification: questionnaire/i18n tests; two-slot and unknown-capacity option tests; PostgreSQL validation tests for all three FFA fields; production build; browser checks for loaded resource icons, green/yellow values, question icons and zero FFA buttons on a two-slot map. No production review was submitted.
