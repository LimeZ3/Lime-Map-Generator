Annotation collection milestone — completed 2026-10-14

Live questionnaire: https://lime-mapgen.netlify.app/ Private owner dashboard and full JSON/CSV exports: /owner.

The annotation collection tool is complete for community use:

  • EN/RU questionnaire with fixed question order, 1–5 ratings, default Not sure, partial submissions, three calibration maps and player context.
  • 14,841 catalog entries; original selection provenance is preserved. All other maps contains 8,794 distinct vault parent maps outside the original selection.
  • Popular-family and least-reviewed invitations, category browsing and pagination; lower-priority outside-selection access.
  • 14,734 entries with overlays, 111,041 verified PNGs in persistent Netlify Blobs; sticky layer settings and controls inside zoom.
  • Map data correction reports, review history/corrections, distinct-participant map counts and private owner data export.
  • Resource icons/colors and field/question icons. Two-slot maps exclude FFA; server validation enforces it.
  • Community effort leaderboard below My reviews.

Leaderboard score = distinct maps reviewed + average answered rating-question count. Only the latest review per participant/map is used, regardless of phase. Calibration reviews count. Numeric ratings and Not applicable count as answered; Not sure and optional text/biome/context fields do not. Scores sort descending; equal scores share ranks. Display names are from current profiles. Empty names receive stable anonymous labels. API exposes only names/anonymous labels, aggregate metrics, rank and own-row flag, never raw answers, notes, ratings/experience, participant UUIDs, tokens or timestamps of individual responses.

Validation completed: questionnaire/i18n tests, real PostgreSQL tests including ranking formula, corrections, unknown/N/A, shared ranks, anonymous labels and public response privacy; production build; EN/RU/mobile browser checks.

Collection may continue. Training and map generation remain later project stages. 107 entries currently lack ready exact-version overlays and retain their explicit unavailable state.
