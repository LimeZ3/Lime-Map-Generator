EXTRACT-05 Supporting slope tensor

Finished: numeric extraction and validated model helper. Selected training integration is a separate follow-up. Receipt and methods: 1,310 maps completed, zero failures, seven tests passed. Existing checkpoints unchanged. Calculate slope and include it alongside terrain where relevant to models. Candidate field is physical steepness 1 x 256 x 256, using physical cell spacing and validity neighborhoods. Downstream models can derive it from their upstream terrain. Terrain slope supervision can be calculated from predicted height; do not supply unavailable clean target slope as an inference condition. Same-resolution target semantics, loader/loss wiring and any loss weight still require validation. The selected terrain model's encoded-gradient loss is not the proposed physical-slope loss. Display-only additions are deferred; current checkpoints/outputs remain unchanged.

EXTRACT-14 Every-map settings and default inventory

Large planned research task; dataset-wide, not five atlas maps. Inventory each map's option IDs, types, choices/ranges, settings count, declared lobby defaults, script fallback/effective defaults, dependencies, affected fields and source logic. Mark unknown/dynamic behavior explicitly; author conventions differ. A player's last-used lobby values are not map defaults. Settings count is not the number of valid combinations. Preserve the default configuration first; later support selected meaningful resource-poor/rich variants as distinct examples and conditions. Do not enumerate all combinations or imply adaptive-map generation.
