Complete questionnaire overlays on Netlify

Live at https://lime-mapgen.netlify.app/ Deploy: 6acf6ceffa330d94fd57ad01 Completed: 2026-10-14

Release: library-2026-10-14 Scope: the 6,130 exact map versions available in the current questionnaire lookup. Images: 45,794 PNGs (3,347,251,709 bytes). 47 catalog entries have no exported exact-version package and retain the unavailable message.

Persistent storage: Netlify Blobs, map-overlays store. Public reads are limited to files listed in the deployed release manifest. Pilot URLs remain supported so open browser sessions can continue using the earlier release.

Upload from apps/crowd-labeler-netlify:

node scripts/upload-overlay-library.mjs
node scripts/check-overlay-release.mjs

The uploader uses the existing authorized Netlify CLI account through Netlify's configuration helper. Credentials are only used in the local process and are never written to the release manifest, browser code, logs, or source archive. 64 bounded workers validate local PNG hashes, upload, read back and hash-check, retry transient failures, and checkpoint each verified result in .private. The release gate checks every checkpoint against the exact deployed manifest.

Before production deployment, the gate must pass. Then deploy the built app and run scripts/verify-overlay-library.mjs. This checks a distributed sample plus native/rectangular test maps, response caching and MIME, unavailable paths and the existing session API. Every file receives full upload read-back verification; HTTP testing uses a sample to avoid downloading the entire library again.

The hosted build defaults to the blob URL and does not copy PNGs into dist. The viewer publishes a compact map lookup; the file hashes stay in the server manifest. Images load on demand when their layers are selected. Native-resolution images load in the enlarged view. Extracted terrain shares exact layer coordinates; custom vault artwork may not. Passability is an estimate; adaptive links represent exported default settings/all recorded slots rather than questionnaire choices.
