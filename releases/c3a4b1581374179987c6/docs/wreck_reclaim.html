Learned Wreck / High-Value Reclaim Pilot

Scope

Add a separate wreck-mass allocation model and composer while preserving the player-approved tree-energy / rock-mass result. High-value natural rocks already contribute proportionally to the existing natural-rock mass field; this new role does not arbitrarily reclassify rocks by a mass threshold. Living civilian structures remain a later layer.

The network learns where enabled wreck reclaim belongs, not unit IDs, exact chunk counts or orientations. The composer selects unit wrecks from a verified pool and applies a chosen physical mass budget. A zero budget disables wrecks.

Data Audit

Reuse physical channel 7 from reclaim_props_curated_256_v1. Sum-pool 256 to 128 and normalize unclipped wreck mass to a unit allocation field. Conditioning is the existing nine terrain/spawn/mex/hydro fields. No total mass is an input.

  • Training: 193 complete positive wreck-mass maps.
  • Validation: 18 complete positive wreck-mass maps, retaining the frozen family split.
  • Exclude unresolved wreck mass on 86 training / 14 validation maps.
  • Exclude known-zero wreck mass on 741 training / 65 validation maps from spatial supervision.
  • Selected known mass: 2,643,319.44 across 211 maps.

Unknown mass is never substituted with zero. Exclusions apply only to this new role experiment, not to the approved terrain/tree/rock datasets. The complete subset can underrepresent complicated or underwater wreck cases; excluded maps are not automatically bad maps. The model does not predict whether wrecks are present; the user's composer budget controls presence and abundance.

Dataset: data/tensors/wreck_mass_heatmaps_128_v1.

Model And Five-Minute Run

Transfer the approved update-20,657 tree/rock EMA feature weights into an independent one-output multiscale U-Net with a fresh output head. This copies parameters, not references to mutable source weights. No approved checkpoint is modified. Backbone LR is 1e-5; fresh-head LR is 2e-4, with the existing spatial NLL / Hellinger / multiscale allocation objective and D4 augmentation.

17,857,281 parameters; 4,460 updates in 300.34 seconds; peak allocated GPU memory 2,262 MB. The full-state latest checkpoint also retains CPU/CUDA RNG states for a future resume implementation. Training has finished; the old tree/rock run remains paused.

Correct Wreck Export

A generic /props/DefaultWreckage/DefaultWreckage_prop.bp record in .scmap does not encode a particular unit's wreck mesh/economy. The installed FAF lua/wreckage.lua supplies CreateWreckage(bp, position, orientation, mass, energy, timeMult), which sets the unit's wreck mesh, blueprint display scale, collision, reclaim values and AssociatedBP rebuild metadata. The generated map script calls that API directly. It does not spawn live units and kill them. API source signatures and SHA-256 hashes are recorded, but in-game execution has not yet been tested for this export.

The initial pool has UEF, Cybran and Aeon T2/T3 ground-mobile wrecks:

These are derived from installed unit blueprints and the inspected FAF tier factors for fully built, zero-overkill, land-equivalent wrecks. Energy is zero for this pool. Values are explicitly assigned, including underwater. There is no automatic water discount in direct CreateWreckage; this composer intentionally does not simulate the normal unit-death layer/overkill pipeline. The distinction is recorded in metadata and the gallery. Changing that policy later must change value budgeting as well, not merely appearance.

Project the learned full field to 180-degree symmetry, allocate mass over 2x2 coarse budget areas (large chunks require larger accounting areas), and sample fine positions from the original 128-grid probabilities. Match unit IDs and values in pairs. Default wreck-to-wreck minimum center spacing is four world units; it does not enforce clearance from trees, rocks, mexes or spawns. No land, water, slope or pathing filter and no terrain/resource repair applies. Budget remainders stay in their areas; there is no uniform fallback or distant refill. A 500-wreck safety cap bounds output.

Use new output folders on reruns. Review/export accepts --mass, --spacing, --seed, --selection last|best and --device cpu|cuda. The test driver is bound to the existing approved seed-303 medium composition. No raw-map rerun, texture training, hosted deployment or destructive cleanup is involved.

Seven new tests cover physical allocation, unknown-value rejection, independent transfer initialization, value budgets, symmetry, underwater retention, spacing, safety limits and generated script identity. Existing reclaim tests also pass.
