Standing Stones: a valid alternative mirror was skipped

27 October 2026. Map 54_56, Standing Stones. The source selected pair is ARMY_1 (86.5,255.5) and ARMY_2 (424.5,257.5). The existing pair is retained.

All distances and heights are world units. Both mirrors independently pass the existing 4-unit source/default marker checks. The targeted rerun also confirms the vertical mirror through the existing movement checks. Horizontal reflection fixes the selected bases approximately in place; vertical reflection exchanges them. Thus a valid map symmetry does not automatically identify the useful opposing-base transform.

The half-turn is a particularly strong terrain fit but two of 46 mexes and the central hydro narrowly exceed the marker gate. Hydrocarbon 00 is at (254.5,254.5): its 1.5-unit offset on each coordinate becomes a 4.243-unit displacement under a half-turn, versus 3 units under either mirror. No threshold has been relaxed.

The implementation error was the early-exit condition candidate size <= accepted group size. After finding a horizontal single mirror it skipped vertical and other single mirrors. Equal-sized groups can have different axes, so this was not a valid completeness assumption. The new search revision equal_size_group_alternatives_v2_1 skips only strictly smaller groups and records accepted source/default alternatives. The scenario audit can consume those alternatives instead of relying solely on the primary label.

The two independently tolerated mirrors must not automatically be combined into an accepted two-mirror/half-turn group: their composition can exceed tolerance, as it does here. Their evidence stays separate. Eight layout tests pass, including a regression reproducing this failure. The earlier bulk outputs are preserved; only this map was rerun. This is not a claim that all maps have been reprocessed with the fix.
