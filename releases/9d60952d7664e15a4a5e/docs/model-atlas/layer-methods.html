Maps, Layers and Tensors — current presentation methods

Draft display update, 25 October 2026. This note describes the updated atlas; layer-review.md preserves the earlier review and evidence inventory.

Scope update: the later owner decision plan takes precedence for new work: symmetry is first; EXTRACT-14 covers the whole dataset; specific atlas-map extraction reruns are out of scope. Missing reference panels below remain historical disclosure, not scheduled tasks. Model-relevant data comes before display-only changes.

Map identity and background rule

Every row uses this fixed order: Setons FAF 8553_17709, Adaptive Canis River 4617_6826, Adaptive Tabula Rasa 9675_18616, DualGap Adaptive by Robustness 8070_26498 (v0014, uploaded 2 July 2023), FAF Beetles 10838_21065.

Entity/marker and analytical overlay previews use a separate official FAF vault image at 10% brightness by default. It is context only, never a tensor contribution. The global Background brightness slider at 0 hides context. Full-resolution layer PNG links open the transparent 1024² layer alone, excluding the vault picture. Each contextual panel labels the background. Registration between custom vault artwork and extracted world coordinates is unverified. The same separate context is available behind every map-layer preview, including terrain, water, pathing, access bodies and surface albedo. Opaque source images become translucent through the mask slider, revealing the context underneath.

Slot identity, mask opacity and extraction TODOs

Air masks are slot-relative, not neutral whole-map fields. Both saved sides are shown: blue SLOT 1, orange SLOT 2 for four maps, violet overlap. DualGap’s archived air pair is SLOT 1 vs SLOT 12: it is flagged as incorrect for the intended SLOT 2 scenario, without moving or relabeling the old masks. Newer frontier paths use the expected SLOT 1 vs SLOT 2. See the maps extraction work queue.

Global sliders range from 0 to 100: Background brightness defaults to 10, and Mask opacity defaults to 100. They stay at the bottom of the desktop sidebar, apply across atlas sections (including model tensor galleries), and remember selections locally when browser storage is available. The former fixed 50% mask-fill rule is superseded. Layer PNGs retain full base opacity; CSS applies the selected display alpha. Background and data remain separate; source tensors, classes, scalar values and extraction results are unchanged.

Resource-zone quality, missing exact versions, contestability definitions and hover/navy path coverage are open extraction/analysis tasks, with warnings beside the affected atlas rows. Walk access and access structure retain their accepted meaning.

Reproduce the display

From the project root in PowerShell:

$env:PYTHONPATH = 'src'
.venv/Scripts/python.exe -m supmapai.tools.atlas_layers
.venv/Scripts/python.exe -m supmapai.tools.build_model_atlas

The comparison renderer reads saved extraction/analysis files and produces only atlas PNGs and comparison JSON/JavaScript under docs/model-atlas/generated. It does not rewrite source tensors or run extraction, training, inference, route optimization, opportunity scoring or economic simulation. Point rasterization, 4-unit display aggregation, color mapping and joining saved IDs are rendering operations. Model-atlas refresh uses the GPU Python environment for metadata only.

Terrain, water and surface albedo previews are rendered without baked-in title/legend frames, with full base opacity and separate vault context. The separate explicit --prepare option remains available for initial local source preparation; it was not used for this display correction. Do not invoke it merely to redraw these views.

Units, scenarios and unavailable outputs

Native source grids are 512² or 1024² cells. Reclaim PNGs sum known values per 4×4 world-unit tile (128² or 256² display cells), then expand with nearest-neighbor sampling to 1024² PNGs. Energy, natural mass and wreck mass have separate shared log scales. Missing amounts remain reported; unknown is not zero. Natural mass includes all natural prop types, whereas the current model's rock-mass role is narrower. Native entity/array values remain linked.

Physical source comparisons show all source slots with saved defaults. Air/drop and contested-region panels use the actual historical collection scenario and medium preset for all five maps; DualGap there uses ARMY_1 versus ARMY_12, while the other four use ARMY_1 versus ARMY_2. Newer whole-economy and frontier results have their own saved setup, which can differ (e.g. DualGap ARMY_1 versus ARMY_2). Do not compare these releases as if they shared every assumption.

Main battle paths now show both saved K3 approaches: own_points in blue and mirror_points (or the saved joined counterpart segment) in orange. Separate rotational contacts are not joined. Historical FAF Beetles paths are colored by endpoint side, with the different method labeled. Hover/navy comparisons remain explicit TODOs.

Main-base/rear/forward fields use existing v1.2.1 whole-economy outputs for Canis, Tabula and DualGap. The exact Setons FAF and FAF Beetles outputs were not found in the checked runs: those two panels explicitly show TODO / unavailable. Stock Setons or stock Beetles are not substituted. Contestable resource regions are a separate saved historical territory classification, not a relabeling of forward/flank or neutral access.

The former atlas air-distance proxy and duplicate Resource abundance stock row have been removed from the displayed section. The old numeric diagnostic archive is preserved as historical data. Access & economy is renamed Walk access from spawn; Gameplay structure is Access structure.
