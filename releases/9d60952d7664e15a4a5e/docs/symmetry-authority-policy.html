Human symmetry authority and preserved spawn pairs

27 October 2026. Owner decision: saved manual symmetry suggestions override automatic detection. Keep the original source pairs on the checked formerly unresolved maps. No further symmetry-selection decision is pending for this cohort.

The resolver src/supmapai/extract/symmetry_authority.py implements this precedence:

  1. Dataset exclusion is independent and takes precedence over eligibility. Never restore an excluded map merely because its symmetry is labeled.
  2. A non-unset human suggestion is the effective symmetry condition, even if a different automatic result is valid. Human None is explicit; human unsure remains unavailable rather than silently reverting to detection.
  3. With no manual suggestion, retain the recorded automatic result and its recorded availability.
  4. Keep measured fit, source/default scopes, coordinates and raw arrays as separate evidence. An override does not average terrain, move entities, or certify exact invariance.
  5. Preserve the original owner-verified pairs on the nine formerly unresolved kept maps. This does not reset the 81 scenario changes elsewhere in the earlier audit. Use actual coordinates in downstream analysis.

The pinned snapshot contains 1,310 maps: 1,255 kept / 55 excluded, including 89 human overrides and 1,221 automatic selections (counts include excluded records). Cold September is now excluded and remains excluded. All seven discussed maps have saved manual suggestions. The override policy is tested independently of detector accuracy.

data/processed/symmetry_authority_v1/effective_records.json materializes the selected authority, human ID or measured descriptor, geometry, curation version, hashes and actual pair for each source map. Filtered setups.json and eligible_manifest.json cover exactly the 1,255 kept maps. Three resolver tests passed; original owner-pair preservation, eligibility and setup parity were checked. This is a data-authority sidecar, not a trained model or a regenerated numeric dataset.
