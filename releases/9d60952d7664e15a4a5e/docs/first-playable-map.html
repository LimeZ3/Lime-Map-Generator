First Playable Map: Achieved

25 October 2026. The project owner played MapGen Heatmap Medium 303 (mapgen_sym_heatmap_medium.v0001) and confirmed:

This map is actually playable. Not good, but also not terribly bad and IS playable.

This is the first explicitly player-confirmed playable milestone for the staged ML pipeline. It is a proof of concept worth preserving and presenting, not a claim of competitive balance, FAF ranking eligibility or general map quality. It does not mean the separate all-in experiment succeeded.

Frozen Presentation Artifact

  • 10 x 10 km, two players, intended 1v1; terrain seed 303, requested water 20%.
  • 32 mex markers, two hydro markers, 2,694 trees and 644 natural rocks.
  • Learned terrain/water, learned resource-marker heatmaps and learned natural reclaim allocation. Supplied starts and deterministic symmetry, finishing, decoding and prop composition. Inherited stock materials, not learned textures.
  • No later wreck pilot or civilian generator is included.
  • No terrain/resource snapping or flattening was re-enabled for this milestone.

Frozen receipt identifies the exact map, original export and game-file SHA-256 values. The existing source and installed game files were verified identical; no map regeneration was performed. The successful direct-map launch log is data/exports/launch_logs/mapgen_sym_heatmap_medium_scenario_20261025_173817_933_utc.log. The log confirms loading; the player's assessment establishes the playability judgment. Neither is an independent balance or full-engine validation study.

Launch Without Codex

The desktop shortcut MapGen - First Playable Demo runs scripts/Launch-PlayableDemo.ps1. It verifies the five installed game files against the frozen receipt, then uses the existing direct-map launcher. No FAF lobby, Python, model inference or training is needed. It refuses to interrupt an already running game and displays an error if files are missing or changed. FAF-patched game files and the installed game are still required. The shortcut uses the same offline inspection launch as this demonstration, with AI disabled. For a normal match, select the installed map in a FAF/game lobby.

PowerShell alternative:

.\scripts\Launch-PlayableDemo.ps1

For a relocated installation, provide -MapsRoot and -GameExe. These must refer to paths mounted by that game installation. -CheckOnly verifies without launch.

The ZIP contains one correctly named map folder with the five byte-identical game files plus a presentation README. Training arrays, composition JSON with local provenance, checkpoints and private paths are excluded. No executable or separate game-asset library is included. The map references installed game assets; it is not a standalone game or seed-only generator.

Recipients extract the whole folder into their FAF/game configured custom-maps directory, refresh the map list, and select MapGen Heatmap Medium 303. This export is ready to share manually; no FAF vault upload or ranking approval has been performed. Preserve the folder name and v0001 artifact unchanged.

scripts/Export-PlayableDemo.ps1 rebuilds the package with frozen ZIP timestamps, verifies source hashes and reads back every packed game file. It refuses to overwrite an existing archive; use -OutputDirectory for a verification rebuild.
