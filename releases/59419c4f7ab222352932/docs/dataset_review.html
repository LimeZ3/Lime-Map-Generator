Local Dataset Review

This is a local curation tool, separate from the public annotation survey. The initial cohort is exactly Full256 V3: 1,200 train + 110 validation maps. No held-out test maps are included. No training, downloads, or hosted deployments are started by this tool.

Open

From Windows PowerShell in the project folder:

.\scripts\Start-DatasetReviewer.ps1

Open http://127.0.0.1:8766. Keep that PowerShell window running; Ctrl+C stops the server. Use -Port 8767 if another application already uses that port. The server binds only to loopback, requires same-origin review tokens for writes, and does not serve arbitrary local files.

Equivalent Python command (NumPy and Pillow required, no GPU or SciPy):

$env:PYTHONPATH = 'src'
.\.venv-codex\Scripts\python.exe -m supmapai.tools.dataset_review

Review

  • Search by actual name, folder/version, family, or dataset key.
  • Filter train/validation, unreviewed/kept/excluded/retained; sort by name, water, relief, or family. Gallery pages contain 24 maps.
  • Each item compares the embedded original map preview with the actual decoded 256 x 256 training target, not a newly generated map. A/B mark the selected 1v1 spawn pair. Source previews are supplied by map authors and can be stale; they are not a fresh engine render.
  • Open an item for larger images, exact spawn coordinates and terrain measurements. Height contrast is scaled per map (1st-99th percentiles); water shade represents decoded depth, with saturation at 30 world units. Width/depth/height values in the detailed measurements remain physical rather than color-derived.
  • Keep marks an item reviewed. Exclude records an exclusion, optionally with a reason and note. All unreviewed maps remain retained by default.
  • Apply To / Whole Family explicitly applies the decision to all members of the existing family in this cohort, after confirmation. Family labels are existing automated groupings, not proof of identical geometry. Versions outside this cohort are not changed. Reset removes a decision; Undo reverses the last operation, including family operations, across browser sessions.
  • In the detail view: Left/Right move between maps; K keeps; X excludes; U undoes; Escape closes. Shortcuts do not run while editing text/select fields.
  • Notes are committed with Keep/Exclude. Navigation alone does not save an edited note. The Saved indicator confirms a disk write; errors remain visible.

Decisions and Selections

Default directory: data/processed/dataset_reviews/terrain_full256_controls_v3/

  • decisions.json: persistent decisions, revision, undo history and source-cohort fingerprint. Atomic replace protects writes. A process lock prevents two servers from overwriting each other, and revision checks protect concurrent browser tabs.
  • catalog.json: cached names and provenance, bound to the published release.
  • images/: on-demand cached PNGs; at most two render jobs run concurrently.
  • selections/<timestamp>_<id>/selection.json: immutable, versioned export created by Export Selection. Includes reasons, source identity, retained/excluded keys, and split counts. Sibling train_membership.json and validation_membership.json carry absolute source archive paths and checksums.

These generated files are already gitignored under data/processed/. Back up decisions.json and exported selections when moving workstations. Existing decisions survive a restart; a changed source release requires a new review directory rather than silently reassigning old decisions.

Nothing is physically removed. The app never edits raw maps, source tensors, existing splits or checkpoints. Exclusion applies to this reviewed cohort, not automatically to every dataset in the project. An export is a membership selection, not a ready-to-train dataset. The next dataset build must consume its retained keys, preserve family split assignments, refit normalization on retained train maps only, re-encode profiles, audit, and publish a new release. Existing model weights will still reflect excluded maps until retraining.

For another compatible full256 cohort, pass -Source and a new -ReviewDir. The reader currently expects the full256/native-source metadata contract; it does not guess how to render arbitrary tensor formats.
