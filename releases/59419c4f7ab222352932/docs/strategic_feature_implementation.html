Meaning and limitations

Amber resources are reachable by weapon radius from at least one candidate naval basin. Blue is candidate reachable water. White resources are outside that computed reach. Results retain can_hit_in_game: null and clearly distinguish range-only geometry from confirmed damage.

Naval factory candidates require skirt-sized deep-water space and build reach from the engineer's connected terrain region. They do not verify exact skirt origins/offsets, roll-off, prop/unit collisions or engine placement. Engineer movement mapping and build-radius rules also need controlled in-game checks. Navigation represents terrain; it does not include all physical unit collisions. Terrain line of fire, projectile ballistics, footprint clearance and target collision geometry remain explicit validation work for the next refinement.

The default reference activates all scenario spawn markers but assigns no guessed teams. Counts include all eligible resource sites, not enemy-owned mexes. An explicit setup file can select slots and teams, but does not manufacture actual resource ownership. Per-opponent ownership/exposure belongs in a later analysis.

Default resources are resolved by our existing supported adaptive adapter or a strict standard-script helper whitelist. Unknown scripts remain static-marker potential; runtime-created/deleted resources are not silently treated as known. Final gameplay training labels must not consume these preliminary counts as confirmed attacks. JSON validity flags identify the permitted review uses.

The full audit passed all 33 maps and 21,162 firing witnesses. Thirty maps have resolved default-resource sets (22 standard static scripts and eight supported adaptive scripts). Project Tabula, Mellow Shallows and Adaptive Pandemonium Pass retain unresolved_static_marker_potential; their script-dependent resource activation needs inspection. No extraction failed.

How grids and paths are implemented

  1. Parse the stored vertex heights and height scale, water-enabled flag/elevation, terrain codes, resource/spawn markers and playable area using the vendored MIT community library.
  2. strategy/navigation.py:raw_layers builds one cell per original terrain grid tile. Each cell compares its four corner-edge height differences to strictly less than 0.75. Average water depth uses the four clipped corner depths; disabled water means zero depth. Terrain codes 9 and 230 block movement, sampled at the far corner as in the pinned source. Playable bounds also apply.
  3. Keep four masks: land = flat and depth zero; naval = depth at least 1.5; amphibious = flat and depth at most 25; hover = flat or depth at least 1. Label side-connected regions independently per mask; 0 means blocked.
  4. Separately retain the source library's AI region grids. These include mixed block compression and culling of small resource-free regions. Land block thresholds are 1/2/4 at map widths below 1024/from 1024/from 2048; naval blocks are twice as coarse, subject to the source tree-size cap. The raw grids avoid throwing away small terrain-accessible islands merely for AI relevance.
  5. The C# adapter passes the raw labels to upstream NavPaths.DistancesFrom: weighted Dijkstra in eight directions. Straight steps cost 1; diagonal steps cost sqrt(2). A diagonal requires both adjoining side cells to be passable. Each spawn/layer field contains shortest travel distance or infinity when unreachable; positions are floored to cells.
  6. trace_distance_route recovers one route by following legal predecessors from the destination through an existing distance field. It checks the float32 shortest-distance recurrence and returns cell centres (x+0.5,z+0.5). This is a cheap display operation, not another full-grid search. The vendored library also contains A* FindRoute, which the batch adapter currently does not invoke.

The demonstration is Adaptive Archsimkats Valley, slots 1 to 2, with no team assumption. Land and amphibious shortest distances both measure 399.806 map units. The overlays differ around water even though this pair's route is the same.
