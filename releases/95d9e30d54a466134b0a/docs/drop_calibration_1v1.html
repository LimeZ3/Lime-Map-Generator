Drop calibration: reward and reinforcement

15 October 2026. Viewer: http://127.0.0.1:5177/drop_calibration_1v1/index.html

This supersedes the first speed-only pilot. It uses shared strict, medium and permissive settings on Astro Crater Battles (2535/3658, slots 1/4), original Seton's Clutch (433/560, slots 1/2), and original The Drunken Beetles Dance (4822/7169, slots 1/6). Only those two slots are active; default map options apply. No map-specific viability overrides or target-count fitting is used.

What changed

  • Arrival advantage alone is no longer sufficient. Both resource reward and a reinforcement window must pass.
  • Offensive/gunship targets are excluded if the base is close or a tank could respond promptly from a main route. The pinned tank weapon range (18 map units) is subtracted before travel time.
  • Initial intel, AA and actual army positions remain unknown. Structural base/route proximity is a protection proxy, never proof of absent defenses.
  • The transport is now the T1 UEF uea0107 (120 mass, 4800 energy, speed 10.75), correcting the previous T2 profile. Nominal production from an existing unassisted T1 air factory is 800 / 20 = 40 seconds. Air raids use the UEF uea0203 gunship (192 mass, speed 13.5), correcting the bomber profile.
  • Small isolated land components up to 50,000 tiles without an active spawn are grouped as island pockets. This prevents spaced mexes on the same island being rejected merely because they were previously separate marker clusters. Full island economy is potential regional value, not a claim that every mex is attacked instantly.
  • Contested islands may be conditional offensive targets if the enemy occupies them. Their ownership is explicitly unknown. Island groups with resource sites advantaged to both players are contested rather than assigned by the first marker alone.
  • Nearby viable patches are grouped into destinations within 160 walking units on the same movement layer. Grouping obeys actual terrain detours and cannot join separate islands. The seed-based grouping is an approximation, not a unique tactical decomposition.

Economic and response measurements

Expansion net saving = walking engineer time - (flight + unload overhead + final ground leg + 40-second fresh transport production). Advance mex income sums 2 × max(net saving - 12 × build index, 0) across T1 mexes. This models sequential construction but omits walking between mexes, so the credit is optimistic. Reclaim is reported but gets no automatic credit. Energy, air-factory build/queue cost, mex investment and combat losses are not converted into mass. Transport-only payback = 120 / (2 × mex count), once all selected mexes are producing; it is not complete expansion ROI.

Ground response = min(response from enemy base, response from any discovered main-route point), using max(distance - 18, 0) / 3.4. Land-disconnected response is unbounded; amphibious, hover, navy, a counter-drop or existing air can still change defense. Gunship response from the enemy base is tracked separately and must meet the preset threshold. This assumes an existing gunship there, not that one is known to exist.

Offensive value is an income-denial ceiling: T1 mex production × min(ground response, 60 seconds), compared with the transport mass for drops or gunship mass for raids. It does not simulate DPS, destruction, payload cost, AA or intel. Both base-distance and response tests are mandatory. If the walking alternative does not exist, head-start credit is unbounded in the comparison and exported as null plus an explicit access-required role; finite transport-only payback remains available.

Review and exports

The viewer switches map, side, preset and opportunity type. Rejected areas are visible with the failed checks. Clicking an area shows route/base response, enemy air travel, net engineer saving, payback, income ceiling, resources and conditional ownership. The parameter and comparison tables show all three settings together.

Each map directory contains opportunities.json, calibration_metrics.csv, area_metrics.csv, opportunity_layers.npz, and transparent preset/side/category PNGs. Main flags and the ordinary area CSV use the corrected medium preset, not the superseded speed-only booleans. Raw timing measurements remain available. Source hashes, unit profiles and map settings are recorded.

Reproduce with PYTHONPATH=src and .venv-codex/Scripts/python.exe -m supmapai.tools.inspect_opportunities. The explicit --calibration flag remains accepted; calibration is now the default. Raw navigation inputs must already exist; use compare_navigation_maps.prepare(key,name) to build a missing navigation-only cache. --rebuild regenerates route/entity caches. No whole-library render, naval sweep or hosted deployment is performed.

Validation and a three-map/preset comparison PNG are recorded in the output directory. All 47 targeted tests and the three-map data/mask/provenance audit passed. Unit tests include fast-flight rejection beside a route, protected base clusters, inaccessible economy, transport production/sequential build costs, nested thresholds, island grouping and terrain-aware destination grouping. Static-map approximations still need review against the intended in-game destinations.
