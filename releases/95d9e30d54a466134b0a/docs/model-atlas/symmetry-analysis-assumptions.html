Measured symmetry and analysis reference frames

26 October 2026. Proposal for discussion, not an implemented fallback. The owner accepted the chosen map symmetry results and requested removal of the automatic "needs review" presentation. The 82 unmatched maps remain unchanged while the owner inspects them. No assumed symmetry is added to source labels.

An asymmetric map can still be examined relative to a candidate mirror or half-turn. That operation is an analysis reference frame, not a claim that all map features obey it. A real selected base pair can define a joining axis, midpoint and perpendicular bisector even on a completely asymmetric map.

Keep the two records separate:

Record Meaning
Detected map symmetry Evidence-backed source/default/terrain descriptor, including no supported match
Analysis reference/assumption Explicit transform used by a particular gameplay estimator

A proposed analysis record should identify the actual source base pair, transform, supporting features, conflicting features, estimation purpose and its limitations. Different layers may support different transforms; no single global assumption needs to replace the measured data.

For routes and resource availability, a frame can align regions for comparison, seed counterpart contacts, or provide a soft routing prior. Both sides must still be evaluated against their actual passability, route distances, resources and reclaim. If a mapped contact is blocked or a corresponding resource is absent, record that difference rather than copying a route/resource into the other side. Resource asymmetry becomes an imbalance measurement, not something to erase.

Choose the reference and its evidence before reporting the target metric. For example, do not choose a transform simply because it makes resource totals look equal and then conclude that the economy is balanced.

Assumed overlays should be visually distinct from detected source masks. They must not silently become ground-truth symmetry conditions or trigger height, texture, marker or prop averaging. A future model could consume a reference frame as its own explicit condition, separate from a symmetry truth label.

No pipeline enforcement, new fallback labeling, model input or training is implemented by this proposal. EXTRACT-13 still requires actual passable contact joining and scenario-aware route construction.
