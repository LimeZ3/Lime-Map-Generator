What this means

Only Standing Stones is demonstrated to be the same missed-equal-sized-mirror case. Fast Rush exposes an audit-scope issue: its saved original default descriptor already confirms the half-turn and selected base swap, but the earlier full-source counterpart audit omitted it. A known active pair must be verified within that scenario; inactive near-coincident slots should not veto it. The new follow-up evaluator validates actual pair swaps against separately verified source/default transform groups.

For the other seven, matching starts are not the failing feature. Source/default resource matching, terrain guards and static movement masks are separate requirements. These failures do not overturn the owner's judgement that the existing spawns are sensible. They also do not establish competitive imbalance. No thresholds were relaxed, nor were unverified transforms promoted to symmetry training labels. Listed mex distances are best tested pair-compatible canonical/proposed transforms, not universal proofs of asymmetry.

Two scope-regression tests passed in addition to the previously passed eight layout and six pairing checks. Every rerun verifies the original native archive and marker checksums. The immutable run records implementation hashes, original settings, owner confirmations and per-map source/default groups. Previous v1 diagnostic outputs are retained as history; the active follow-up is v2.
