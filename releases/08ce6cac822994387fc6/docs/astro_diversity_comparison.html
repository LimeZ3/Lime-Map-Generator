Computed 14 October 2026 using the current corridor-cut / symmetry / merged-section implementation. No blueprint parsing, naval reach calculations or library-wide extraction was performed.

Configuration

  • Astro Crater Battles: map 2535/version 3658, original folder astro_crater_battles.
  • Adaptive Diversity: map 4619/version 6828, adaptive_diversity.v0002.
  • Both 512 x 512. Selected route endpoints ARMY_1 to ARMY_2.
  • All scenario slots active: six for Astro, sixteen for Diversity. Default adaptive settings only. Teams are not inferred.
  • This is a comparison of one opposing base pair, not a complete team-game attack network. All-map resource counts describe these configurations and are not normalized for player count.
  • Existing MaxSlope .75, amphibious maximum depth 25, obstacle filtering and search budgets retained.

The other two mexes and two hydros are land-disconnected. Amphibious and hover can reach all 112 mexes and all eight hydros. Astro has 42 mexes and six hydros, all land-reachable.

The resource distance overlay separates route proximity from nearest-route territory membership. Territory membership alone previously associated all reachable resources with routes even if the resource was far away. The new distances use weighted eight-neighbor movement with no diagonal corner cutting. Resource sites on blocked cells are not snapped; disconnected sites are explicit. Here the two land-disconnected Diversity mexes are passable local cells in disconnected components, not blocked marker cells.

Interpretation and limits

Astro concentrates the chosen bases' ground access into one route family. Diversity supports several obstacle-separated alternatives and has substantially more economy distant from those routes. The reduction from 78 far mexes when using only the shortest route to 28 when using all discovered routes demonstrates why alternatives matter.

Distance bands 32/64 are inspection thresholds, not validated safety or weapon ranges. Far from a route is distinct from far from a base. The base-response distance here is to any active base, without teams, so it is an optimistic lower bound for friendly response. Neither distance proves air vulnerability, AA coverage, army presence, drop effectiveness or behind-base safety. Those need team assignments, base-front orientation and unit ranges/timings.

Widths belong to the representative polylines, exclude 32 units at both endpoints and do not model unit footprints, props or army formations. Multiple routes can share sections. The algorithm is greedy, not exhaustive; Diversity amphibious and hover explicitly hit the cut budget. Equal route counts for these layers do not imply identical paths.
