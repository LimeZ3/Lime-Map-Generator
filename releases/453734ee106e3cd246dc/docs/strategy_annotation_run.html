Commands

Run these from C:/Users/limon/OneDrive/Documents/MapGen in PowerShell:

.\scripts\strategy-annotation-batch.ps1 -Action Status
.\scripts\strategy-annotation-batch.ps1 -Action Pause
.\scripts\strategy-annotation-batch.ps1 -Action Resume

Pause is graceful: stop dispatching, finish the active maps, publish exports, then record paused. It can take up to the worker timeout to drain. Resume starts a hidden background controller, reuses completed outputs, skips recorded failures and continues unfinished stages. It never automatically retries failed maps or historical download failures. A duplicate controller is rejected by an OS lock. If an earlier controller crashed, its surviving workers must release their OS leases before new maps are dispatched. The controller keeps Windows awake while processing; the machine must remain on.

Progress and traceability

data/processed/strategy_annotation_batch/latest_run.json identifies the run. Inside that run folder:

  • status.json: controller state, heartbeat, complete/excluded/failed/pending counts, current worker stages and elapsed times. A fresh heartbeat means the controller is alive. A slow map can remain in one stage for several minutes. waiting_for_orphan_workers means it is deliberately avoiding overlapping work.
  • events.jsonl: append-only controller/session/map start/finish/error history.
  • jobs/<key>/attempts/0001/worker.log: each attempt's retained stdout/stderr. Failure JSON includes stage and Python traceback where available. Attempt numbers increase on resumed interrupted work; earlier attempts stay intact.
  • failures.json: aggregate failures/exclusions with names, IDs and reasons.
  • controller_failure.json: traceback if the controller itself stops.
  • run.json, runtime.json, code_snapshot/, controller_snapshot.py, reuse_manifest.json: scientific inputs, operational identity and provenance.

Exports refresh every three minutes and on graceful pause/completion. The live HTML page checks the heartbeat every ten seconds; reload it to refresh labels. A completed scientific result is eligible for export only after its independent audit and previews finish. Pending, excluded and failed maps never become zero scores or training examples.

Training handoff

labels.csv and labels.json include raw values, ratings, per-axis validity and confidence. training_manifest.jsonl indexes audited examples and source hashes; train.jsonl, validation.jsonl, test.jsonl and quarantine.jsonl separate whole families. Exact parent IDs, normalized names, app family hints and identical SCMAP bytes are joined before extraction. Pilot split anchors are preserved; conflicts between old splits quarantine the entire joined family. Duplicate detection is conservative, not exhaustive visual similarity clustering.

The manifests reference per-map arrays, metadata and local sources. Model-specific tensor packing and dataloaders are a separate training step. Use per-axis loss masks and omit quarantine families. Save a snapshot of these incrementally updated manifests when training begins. A partial run is usable without pretending it is the entire cohort. label_validation.json, validation.json and summary.json record the aggregate checks and coverage at each export.

Known limitations remain those of the pilot: static 1v1 opportunities, mass-only economy, representative air/naval units, no actual AA/intel/army positions, naval projectile blocking omitted, and front width measuring route bottlenecks rather than an overall competitive-quality judgement. Low reclaim confidence and missing axes stay explicit.
