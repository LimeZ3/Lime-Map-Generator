Source inventory for the proposed joint diffusion experiment

Inspected 25 October 2026. This is a dataset inventory, not a new training release. No training, CUDA initialization, source changes, or checkpoint changes were performed.

Cohort

The reviewed cohort is data/tensors/terrain_curated_20261024_v1: 1,117 maps, comprising 1,020 train and 97 validation, with one representative per curated family. terrain_curated_overnight_v1 contains the same map keys in the same splits. It is not an additional independent cohort.

Resources, typed reclaim, natural-reclaim allocation, and texture V2 manifests contain exactly those same 1,117 keys, family IDs, and splits. The wreck allocation release is a 211-map subset with matching families and splits.

The underlying selected scenarios are 10km / 1v1. Each retained source metadata record has two selected starts. These are not inventories of every army slot in the original map. Preserve the selected scenario when pairing sources with its gameplay ratings.

Typed physical reclaim uses a small Gaussian raster blur. Its encoded targets also have clipping. These are existing representations, not a claim of raw, unmodified source quantities. Original entity records are available for a fresh rasterization using the requested natural-reclaim and civilian definitions. Living civilian units/buildings were deliberately omitted from typed reclaim targets. A checked original source example, 14516_31025, contains 12 identified civilian buildings despite their absence from those targets. Cohort-wide civilian identity/activation completeness was not established by this inventory.

A follow-up source-kind scan on the same date found 24,973 identified civilian records: 22,037 buildings and 2,936 units. Of these, 24,968 have finite coordinates inside the 512-world-unit canvas; five are outside or invalid. These usable records occur on 217 maps (201 train, 16 validation). The remaining 900 maps have no identified in-canvas civilians under this static source definition. All identified civilian records have unspecified activation status, so these counts describe extracted source placements, not a runtime/lobby activation audit. The scan read the 277 original entity files whose typed-raster summaries record skipped entities; civilians cannot enter that rasterizer's retained prop/wreck groups. Detailed counts are in .tmp/civilian-source-coverage-20261025.json.

Raw texture mask dimensions genuinely vary: 8 x 256 x 256 on 227 maps, 8 x 512 x 512 on 882, and 8 x 513 x 513 on eight. The saved RGB is consistently 3 x 256 x 256 on all 1,117. Native vertices having an extra edge row/column is also distinct from a different map extent.

Ten rating fields are valid on all 1,117 maps. Front openness and army control demand are each unavailable on five training examples. Ratings describe the saved automated gameplay policy, rather than general quality or community votes.

The 853-map intersection is a preliminary complete-case candidate, not a sealed joint dataset. Natural-layer semantics, civilian activation/coverage, source alignment and numeric round trips still require checking before training.

Consequences for the proposed baseline

Use the curated keys and corrected splits as the join authority. A 256-square joint target is feasible from existing native geometry, exact source coordinates, entity records and saved RGB; upscaling the 128-square allocation targets is unnecessary. The existing packed targets cannot simply be concatenated because they have different meanings as well as resolutions.

For the requested source-only experiment, exclude the existing shoreline-distance, passability, front/access and supplied-anchor conditioning contracts. Generate starts as target channels. Build the requested all-natural energy/mass layers from their source entity definition, keep wreck mass separate, and rasterize a distinct living-civilian layer. Use absolute quantities through reversible scaling rather than per-map unit-sum allocation targets.

The detailed inspection output is saved at .tmp/joint-source-inventory-20261025.json. Every referenced archive header and release-manifest artifact hash was checked; no missing inspected archives, manifest hash errors, or unexpected header shapes were found. This was not a full numerical re-audit of every array or a game-runtime validation.
